# Delivery checklist and authoring trial report

Copy this into the private task evidence folder. Link artifacts rather than committing private inputs or renders. Report incomplete work plainly.

## Delivery checklist

- [ ] Original files remain unchanged; before/after hashes recorded.
- [ ] Output format and identity are explicit; file loads through the intended inspect/render path.
- [ ] Editable artifact, dependencies and exact reproduction steps are accessible to the recipient.
- [ ] Backend, renderer/runtime versions, input hashes and effective controls are recorded.
- [ ] Before/final comparisons use identical controls; actual images were visually reviewed.
- [ ] Front/side and supported sitting/lying or feature-revealing views reviewed; failures listed.
- [ ] Each defining image feature is matched, approximated or unresolved with evidence.
- [ ] No diagnostic markers or unintended section/row losses remain.
- [ ] Existing ears/tails are reshaped in place; no hidden, parked, zeroed or recreated substitutes, and no blanket stock-add omissions.
- [ ] Ball order, attachment parents, connector endpoints, valid textures and variations are preserved; intended changes are explicitly inventoried.
- [ ] Shared ear/tail recipes were reused; any missing capability is recorded for central research with the original anatomy retained.
- [ ] Variation preservation or normalization is disclosed; variation/growth coverage is explicit.
- [ ] Saved-cache behavior and adult/young resources checked if relevant.
- [ ] Native installation/game checks are reported as performed or untested; preview success is not called game validation.

## Guide assessment

- Could you start from the brief without reading the entire research history?
- Which exact instructions were ambiguous, wrong, stale or missing?
- Which controls could you choose confidently, and which needed new experiments?
- What external information or tools did you need, and why?
- What assumptions about the image most affected the result?
- Which three changes to the guide would most improve a second attempt?
- What must be researched before promising broader reliability?

This report assesses an authoring attempt. A single successful attempt does not establish general image-to-breed capability or game fidelity.
