# EYE-001: pupil, iris ring and host-eye color

Date: 2026-11-09. Status: Petz 4 renderer-observed/code-supported, not game-validated. Scottie and Siamese. Environment/revision matches SMOKE-001.

## Procedure

Run `scratch/petz-local-venv/bin/python tools/eye_color_probe.py`. Use seed-resolved fixed-span copies, preserving all existing section rows. Five variants per species: control; fill=125 on both iris balls; outline color=125 on both iris balls; outline color=125 on the right iris only; fill=125 on both host eye balls. Overrides append targeted rows, leaving every unrelated resource unchanged.

Thirty direct asset loads cover standing, sitting and lying. Assertions check unchanged complete posed geometry and exactly the intended ball-info IDs. Standing eye-overlay commands are recorded separately to establish fill/outline routing. Eight local MCP aligned comparisons use standing, yaw 0°, seed 0, age 100, fatness 50. All eight pairs have different pixel hashes; all eight comparison images were visually reviewed.

Private PNGs/metadata/copies: scratch/research/eye-001. [Public controls/hash/check manifest](eye-001.json). Script reruns overwrite private evidence.

## Findings

| Element | Dogz right / left | Catz right / left | Observed effect |
| --- | --- | --- | --- |
| Host eye balls | 32 / 8 | 15 / 14 | Fill changes outer eye region; iris/pupil colors retained |
| Iris balls, fill | 38 / 14 | 28 / 27 | Pupil center changes; surrounding ring color retained |
| Iris balls, outline color | 38 / 14 | 28 / 27 | Colored iris ring changes; pupil center retained |

In the front view, the asset's right iris appears on the viewer's left for both sampled breeds. The right-only outline edit changes that eye alone. This observation applies to the tested view, not arbitrary camera orientation.

Prepared overlays confirm fill=125 only for pupil edits, second color=125 only for iris-ring edits, and host fill=125 only for host edits. No radius or position changes occur in any of the three numerical poses. Edited sitting/lying images were not rendered here; geometry equality does not replace visual eye-clipping validation.

The implementation draws iris commands inside host-eye overlays rather than treating iris balls as independent ordinary circles. That supports targeting the correct fields instead of recoloring the eye host when a user requests iris color. Original iris outline modes and sizes were preserved; this is not a test of every outline mode, texture interaction or eye-shape control.

The pupil/ring distinction agrees with [Shadowfinder's iris-color tutorial](https://petzhexing.weebly.com/iriscolour.html). Native game fidelity, saved caches, other breeds and edited cross-version behavior still require validation.
