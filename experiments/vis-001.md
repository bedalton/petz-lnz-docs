# VIS-001: geometry behind unchanged omissions

Date: 2026-11-09. Scope: Petz 4 Scottie/Siamese, local renderer geometry API. Code-supported numerical observations; no new raster renders or native-game validation.

Run `scratch/petz-local-venv/bin/python tools/visibility_geometry.py`. The script checks breed hashes and checkout revision against [OMIT-001](omit-001.md), then loads seed 0, age 100, fatness 50 in standing, sitting and lying poses. It selects exactly the IDs unchanged in both standing omission views. No files are edited. [Manifest](vis-001.json) records geometry, controls, source/master hashes, installed Python source-tree hash and runtime. The tree hash fingerprints the installed implementation independently of the checkout revision; it does not certify equivalence to that checkout. Shared binary engines are not separately fingerprinted by this experiment.

## Results

| Species | IDs | Numerical result in all three poses | Interpretation |
| --- | --- | --- | --- |
| Dogz | 4, 5, 28, 29, 65, 66 | `visible=false`, positive radius | Already omitted; another identical omission is redundant |
| Catz | 37, 65, 66 | `visible=false`, positive radius | Already omitted |
| Dogz | 63, 64 | Radius 0, `visible=true` | Zero-radius geometry despite the visibility flag |
| Catz | 57–62 | Radius 0, `visible=true` | Zero-radius geometry despite the visibility flag |
| Dogz | 14, 38 | Radius 6, `visible=true` | Iris overlay exception already tracked by OMIT-001 / GAP-004 |
| Catz | 27, 28 | Radius 5, `visible=true` | Same iris exception |
| Catz | 55, 56 | Radius 4 standing, 1 sitting/lying; `visible=true` | Positive geometry remains unexplained by omission pixels |

These groups account for all 10 Dogz and 13 Catz IDs unchanged in the two-view sweep. Zero radius is a numerical explanation candidate, not proof that an ID has no effect: lines, projection targets and other dependent details can still use a position. Likewise `visible=true` is a geometry field, not proof of a visible raster contribution.

Catz 55/56 are the only remaining positive-radius, non-iris, non-omitted cases in this set. Occlusion is a hypothesis, not an observed fact. The changed radii make more poses worth testing, but this experiment does not claim sitting/lying pixel equality. Render those poses and additional angles before classifying them or promoting anatomical identities. Existing stock label evidence remains separate.

## Limits and next work

Only three default pose frames and two breeds were loaded; no animation sweep, young resources, other versions or native-game behavior were tested. Original OMIT-001 pixel observations remain standing yaw 0°/90° only. Next: focused local MCP comparisons of Catz 55/56 across poses/angles, then iris/host combinations. No renderer correction is justified by these numerical results alone.
