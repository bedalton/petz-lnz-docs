# VIS-002: focused Catz 55/56 omission views

Date: 2026-11-09. Scope: Petz 4 Siamese, renderer-observed. No native-game validation.

## Method

Run `scratch/petz-local-venv/bin/python tools/visibility_views.py`. Reuses the private, validated synthetic branch copy from [OMIT-001](omit-001.md); no original or experimental breed is edited. Each local stdio MCP contact sheet holds a control, omission 55, omission 56 and omission 24 (head, a positive change control). Branch seeds select only the omission difference; original variation alternatives were already resolved at seed 0. Common-scale cells are compared within each sheet.

Standing, sitting and lying default frames are sampled at yaw 0°, 90°, 180° and 270°, age 100, fatness 50. Twelve sheets give 24 target observations and 12 head controls. Raster seed is fixed by the contact-sheet implementation. [Manifest](vis-002.json) records selection seeds, controls, PNG/cell hashes, input/source/master hashes, Python version, renderer revision and installed Python source fingerprint. Private PNGs and MCP metadata remain under scratch/research/vis-002.

The script resumes an atomic checkpoint after checking source/input hashes, completed PNG hashes, runtime version and installed Python fingerprint against [VIS-001](vis-001.md). Master hash and checkout revision are checked too. Shared binary engines are not separately fingerprinted; unchanged external runtime dependencies remain an assumption. Archive the private output before changing the experimental design; resume is for this fixed matrix only.

## Results

| Pose | Yaws | Omit 55 unchanged | Omit 56 unchanged | Omit head changed |
| --- | --- | --- | --- | --- |
| Standing | 0, 90, 180, 270 | 4/4 | 4/4 | 4/4 |
| Sitting | 0, 90, 180, 270 | 4/4 | 4/4 | 4/4 |
| Lying | 0, 90, 180, 270 | 4/4 | 4/4 | 4/4 |

All 24 target cells are pixel-identical to their sheet control. All 12 head controls differ. Native-resolution visual review covered standing/front, sitting/yaw 90° and lying/yaw 270° sheets; the remaining nine have automated hash comparisons only.

Stock labels identify 55/56 as tongue1/tongue2, but this experiment does not visually confirm those identities. VIS-001 found positive radii (4 standing, 1 sitting/lying) and geometry visibility flags for both IDs. Additional yaw/pose sampling still produces no observable omission contribution. Occlusion remains plausible, but these results do not isolate it from drawing rules or establish that the balls are always invisible.

## Limits and next work

Only three default animation frames, four horizontal views and one breed were sampled. This is not an open-mouth animation test. No paired omission, movement, recoloring or isolation edit was performed. Next: seek a frame exposing the labeled tongue region or a controlled isolation probe before attributing the no-op to occlusion; separately test iris/host omissions. This result does not justify a renderer fix or universal omission rule.
